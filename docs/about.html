About this record

Lowdown publishes one record per UTC day. Each record keeps different kinds of facts apart. Nothing here is a score, a ranking, or a verdict about any server.

1. Registry declarations

What the official MCP Registry declares (latest version of each name), compared with the previous day's list. These are the Registry's own declarations, recorded by Lowdown since 2026-10-19. Names are grouped by remote host; servers on the same host are not necessarily the same service. Description, package and remote changes are shown as "changed" only; their contents are not published here.

2. Lowdown observations

A fixed sample of Registry servers is probed once a day from one network location (GitHub Actions) with initialize and tools/list. Lowdown never calls tools. Only counts are published here. A server that was not reached was not reachable from that location at that time; this is not evidence that it is down, broken, or malicious.

3. Tool definitions

For servers reached on two consecutive runs, Lowdown compares hashes of the tool definitions (names, descriptions, schemas). A change means the definition differs from the previous run. It is not evidence of malicious intent, and an unchanged definition is not evidence of safety. Descriptions are not published.

4. First observed by Lowdown

A value (capability key, protocol version, or tool name) that Lowdown had not seen before within its own sample. It does not mean the value is new to the market. Tool names are listed only when seen on at least two hosts and two Registry namespaces.

Data and feeds

  • Daily JSON for each record: days/YYYY-MM-DD.json (the HTML pages and feeds are generated from these files).
  • Latest record at a fixed address: days/latest.json (a copy of the newest daily JSON).
  • RSS and JSON Feed: one item per day, last 30 days.
  • Raw observations: lowdown-data and Hugging Face.
  • Per-server lookup: https://lowdown-proxy.vercel.app/api/reputation/mcp:<registry name>
